# Defense Contractor Store Project

This project involves customizing a web application for an online store of a defense contractor. The tasks include modifying the HTML user interface, adding new features, and ensuring proper functionality through validation and testing.

## Project Overview

The project leverages Java for backend logic, JUnit for unit testing, and HTML/CSS/JavaScript for frontend development. The goal is to create a robust and user-friendly online store with a military-inspired theme.

## Features and Enhancements

### HTML User Interface Customization

The HTML user interface was extensively customized to include product names and part names, styled with a military-inspired theme to resonate with the defense contractor's branding. This involved crafting a cohesive design language that enhances the user experience while maintaining a professional and rugged aesthetic.

### About Page

An "About" page was created to provide a brief summary of the store's mission and values, along with navigation links to other sections of the site. This page offers users an insight into the store's background and purpose, fostering trust and engagement.

### Updated Inventory

The inventory was expanded to include five new parts and five new products, demonstrating the application's ability to handle a diverse range of items. This update showcases the system's scalability and its capacity to manage an extensive inventory efficiently.

### Buy Now Button

A "Buy Now" button was integrated next to the update and delete buttons, facilitating a faster purchase process for clients. This feature streamlines the user journey from browsing to purchasing, enhancing the overall shopping experience.

### Maximum and Minimum Inventory Tracking

Fields for maximum and minimum inventory levels were introduced to ensure effective inventory management. These fields help prevent stockouts and overstock situations by maintaining optimal inventory levels.

### Validation

Comprehensive validation was enforced throughout the application. Error messages were added to inventory fields to ensure users adhere to inventory limits. This validation mechanism prevents incorrect data entry and enhances the accuracy of inventory management.

### Unit Tests

Unit tests were meticulously crafted and executed using JUnit to verify the functionality of maximum and minimum inventory fields. These tests ensure that the inventory tracking mechanisms work as intended, providing a reliable and error-free user experience.

## Maintenance Guide

1. **Prerequisites**:
   - Java Development Kit (JDK) installed
   - Integrated Development Environment (IDE) such as IntelliJ IDEA or Eclipse
   - Web browser for testing

2. **Setting Up the Project**:
   - Clone the repository or download the project files.
   - Open the project in your IDE.
   - Ensure all dependencies are resolved and the project builds successfully.

3. **Running the Application**:
   - Launch the application from your IDE.
   - Open a web browser and navigate to the application URL.
   - Test the application by navigating through different sections and performing various actions such as adding, updating, and deleting inventory items.

4. **Running Unit Tests**:
   - Execute the unit tests using your IDE's built-in test runner.
   - Verify that all tests pass successfully.
   - Review any test failures and resolve issues as needed.

5. **Updating the Application**:
   - Make necessary changes to the source code.
   - Commit and push changes to the repository.
   - Redeploy the application to the production environment.

## User Guide

1. **Accessing the Website**:
   - Open your web browser and go to the defense contractor store website.

2. **Browsing Products**:
   - Navigate to the "Products" section to view available products and their details.
   - Use the search and filter options to find specific items.

3. **Viewing Prices**:
   - Prices for each product are displayed in USD, CAD, and EUR.

4. **Making a Purchase**:
   - Select your desired product and click the "Buy Now" button.
   - Fill in your personal and payment details.
   - Review your order and click "Confirm Purchase".

5. **Managing Inventory**:
   - If you have admin access, navigate to the "Inventory" section.
   - Add new products by filling in the required details and clicking "Add Product".
   - Update or delete existing products using the respective buttons.

6. **About Page**:
   - Visit the "About" page to learn more about the store and its mission.
